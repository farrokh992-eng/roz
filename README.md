# روزنگار | Rooznegaar — Android + GitHub Actions

این مخزن یک اپلیکیشن بومی اندروید است؛ برای ساخت APK به Android Studio نیاز نداری. GitHub Actions خودش فایل APK را می‌سازد.

## راه‌اندازی
1. یک repository جدید در GitHub بساز.
2. تمام محتویات ZIP را در ریشه مخزن قرار بده.
3. در صورت امکان مخزن را روی `main` نگه دار.
4. وارد زبانه **Actions** شو و در صورت نمایش هشدار، workflowها را فعال کن.
5. یک بار در مخزن روی **Actions → Build Android APK → Run workflow** بزن؛ یا فایل‌ها را push کن تا خودکار اجرا شود.
6. پس از سبز شدن workflow، اجرای آن را باز کن و در قسمت **Artifacts** فایل `Rooznegaar-APK` را دانلود کن.
7. ZIP مربوط به Artifact را باز کن و `Rooznegaar.apk` را روی گوشی نصب کن. اگر لازم شد، اجازه نصب برنامه از این منبع را به مرورگر/مدیریت فایل بده.

## انتشار APK در Releases
برای ساخت Release خودکار، یک tag مانند `v1.0.0` ایجاد و push کن. Workflow APK را می‌سازد و به GitHub Release همان tag پیوست می‌کند.

## ویژگی‌ها
- تاریخ شمسی در اعلان دائمی
- نام روز، روز، ماه و سال
- منطقه زمانی تهران
- تلاش برای راه‌اندازی مجدد پس از reboot
- رابط فارسی و مینیمال
- بدون نیاز به اینترنت برای نمایش تاریخ

## نکته درباره اعلان‌ها
در Android 13 به بعد اجازه اعلان را تأیید کن. بعضی گوشی‌ها برای پایداری سرویس نیازمند اجازه Auto-start یا خارج‌کردن برنامه از بهینه‌سازی باتری هستند.

این پروژه سورس آماده ساخت است؛ اولین اجرای GitHub Actions کامپایل واقعی را انجام می‌دهد. اگر خطایی رخ داد، متن خطای همان workflow برای اصلاح دقیق لازم است.
